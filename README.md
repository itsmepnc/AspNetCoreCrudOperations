# CRUD Operations Project with ASP.NET Core

## Overview

This project demonstrates how to perform CRUD (Create, Read, Update, Delete) operations in an ASP.NET Core application using the following frameworks and libraries:

- **Bootstrap 5.3.5** for responsive design and styling.
- **jQuery 3.7.1** for client-side operations and dynamic DOM manipulation.
- **Microsoft.EntityFrameworkCore** and **Microsoft.EntityFrameworkCore.SqlServer** for ORM-based database interaction with **SQL Server**.
- **Microsoft.AspNetCore.Mvc.Razor.RuntimeCompilation** for enabling runtime compilation of Razor views.
- **Microsoft.VisualStudio.Web.CodeGeneration.Design** for scaffolding and code generation.
- **Westwind.AspNetCore.LiveReload** for live reloading of the application during development.

This project allows the user to interact with a **SQL Server** database by adding, viewing, editing, and deleting records through a user-friendly web interface.

---

## Features

- **Bootstrap Styling:** The application uses Bootstrap 5.3.5 for responsive design, ensuring that the web pages look great on both desktop and mobile devices.
- **CRUD Operations:** Users can create, read, update, and delete records in a **SQL Server** database through the web interface.
- **Entity Framework Core:** Used for data access and interaction with **SQL Server**, supporting migrations and database updates.
- **Live Reload:** Integrated live reload functionality to instantly view changes during development without refreshing the page.
- **Razor Views:** Razor views are used for the frontend rendering of the pages, leveraging runtime compilation for on-the-fly updates.
